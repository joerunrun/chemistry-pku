# 双眼确认后的自更新验证

2026-10-20，在连接的 RayNeo X3 Pro（Android 12 / API 32）上验证通过，教师、学生两版分别完成一次自更新。

- 保留原有双眼更新页、滑动选择、单击确认和双击返回。
- Android 12 及以上使用 PackageInstaller 自更新，申请免第二次系统确认；不模拟点击系统按钮。旧系统继续使用原安装入口。
- 两版均从验证包 versionCode=7 自主更新到 2.5（versionCode=8），安装回调为 STATUS_SUCCESS，没有 STATUS_PENDING_USER_ACTION；未点击系统安装确认。
- 验证包使用本机临时更新源，目标包恢复正式服务器地址；测试连接和临时服务已清理。
- 这副眼镜的两版均已装为 2.5，覆盖安装保留数据。本次未修改服务器发布版本，尚未面向其他眼镜发布 2.5。

首次从 2.3／2.4 换成修正版，仍需电脑协助安装一次。现有一键更新脚本会在 USB 安装后允许助手安装更新；仅修改服务器不能改变旧程序的系统安装入口。

系统仍可能因安装来源许可或固件策略要求确认，代码保留该回调处理。本结论限于上述设备实测，不承诺所有固件都免确认。
