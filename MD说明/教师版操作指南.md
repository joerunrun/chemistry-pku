# 化小北教师版操作指南

联网版 2.4｜2026-10-19

连接 WiFi，打开“教”图标，听到“助手就绪，请说指令。”即可使用。

直接说“小北助手，＋你的需求”，一句话说完，不用先等待“我在”。例如：“小北助手，拍张照片。”

**进入教师版后会持续记录声音；停止录像后仍会继续录音，退出软件才停止。**

## 功能和提示音

| 功能 | 一句话示例 | 会听到的提示音 | 效果 |
| --- | --- | --- | --- |
| 持续录音 | 进入软件后自动开始 | 助手就绪，请说指令。 | 自动保存并上传巡视、讲解的声音，不用另说“开始录音”。 |
| 拍照 | 小北助手，拍张照片。 | 开始拍照，请保持画面稳定。<br>拍照完成。 | 保存照片并自动上传。单击镜腿与语音拍照走同一流程。 |
| 开始录像 | 小北助手，开始录像。 | 开始记录。 | 开始录制视频，声音记录继续进行。 |
| 结束录像 | 小北助手，停止录像。 | 记录已停止。 | 结束并保存本段录像；持续录音不会停止。 |
| 意见反馈 | 小北助手，开始反馈。<br>小北助手，结束反馈。 | 开始收集反馈。<br>结束收集反馈。 | 持续收集建议，结束后单独上传语音并转写，不计入日常记录。 |

拍照时请短暂保持视野稳定，照片会自动上传。

没有回应时，稍等几秒，再把完整需求说一遍。 录音、录像、反馈期间只响应各自的结束指令，结束后再使用其他功能。

## 镜腿操作

| 操作 | 效果 |
| --- | --- |
| 单击镜腿 | 空闲时拍照；录音、录像、反馈或视频播放期间不切换功能。 |
| 快速双击镜腿 | 退出软件，结束本次持续录音。 |
| 空闲时长按镜腿 | 检查更新；有新版时选“立即更新”，按系统提示安装。 |

## 网页工作台

打开 http://162.105.209.134/login ，用北大账号登录。

| 入口 | 操作 |
| --- | --- |
| 我的眼镜 | 选择 01—12 号眼镜和固定使用星期，保存后自动归属新资料，无需每次认领。 |
| 我的资料／学生数据 | 查看、下载自己的录音、录像、照片；“学生数据”可查看学生采集资料。 |

| 意见反馈 | 集中查看师生反馈文字、原始语音、时间及眼镜编号。 |

眼镜号或星期选错、旧资料找不到时，请联系管理员处理。
