# 独立头部交互对比测试

同一模块生成两个独立 App，可以同时安装，不依赖后端、教师助手、相机或麦克风。

- A 头部动作测试：右上图标固定显示，向右转约 8–55°并抬头约 3–45°，保持 3 秒触发；计时期间范围稍宽，容忍轻微抖动。
- B 十字边沿测试：细十字初始在中央，转头控制移动；进入右上边沿区域后出现图标，对准图标保持 3 秒触发。十字可去其他边缘，但第一版仅右上区域有入口。
- 成功后显示次数并播放短提示音；回正保持 0.4 秒后才能再次触发。
- 单击镜腿（或屏幕）以当前头部方向重新校准，双击退出。启动/切回 App 时请正视前方。
- 两个 App 使用透明背景，只绘制文字、图标和十字。
- 正数左右角度代表右转，正数上下角度代表抬头；用于戴镜确认轴向。真实方向、舒适度和误触率需要佩戴验证。

编译：在仓库根目录运行 `./gradlew.bat :head-wake-tests:assembleGestureDebug :head-wake-tests:assembleCursorDebug`。
包名分别为 `com.chemistry.headwaketest.gesture` 和 `com.chemistry.headwaketest.cursor`。
